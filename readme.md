# Adaptive Fault-Tolerant Distributed Task Execution System

A Distributed Computing project implementing a distributed task-execution backend using Java RMI.

- Remote task execution
- Worker server
- Client
- WORD_COUNT task

- Multiple worker nodes
- Coordinator / Leader
- Load balancing
- Multithreading
- Heartbeat and failure detection
- Bully election
- Ring election
- Data replication
- Clock synchronization
- Fault recovery
- MapReduce / MPI workloads
